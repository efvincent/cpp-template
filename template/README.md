This project is generated by cargo-generate and uses:
- C++26 modules
- Makefile build modes (debug, release, lto, instrument)
- Dynamic module discovery for all `src/**/*.cppm` and `third_party/cpp-core/src/**/*.cppm`
- `make bear` compile database generation with Clang `-MJ` fragments
- `cpp-core` from https://github.com/efvincent/cpp-core as a git submodule

## Requirements

- clang++ with C++26 modules support
- make
- git
- cargo-generate

## Generate

From the template repository root:

```sh
cargo generate --path . --name my-cpp26-app
```

If your target folder is not already a git repository, initialize it before first build:

```sh
git init
git add .
git commit -m "initial scaffold"
```

## Build and tooling

```sh
make
make release
make lto
make instrument
make bear
make verify-submodule-pin
make clean
make clean_all
```

The first build runs `ci/init_cpp_core_submodule.sh` to ensure `third_party/cpp-core` exists and is initialized.
